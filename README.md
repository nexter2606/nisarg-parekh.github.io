# Nisarg Parekh — Professional Odoo Portfolio

This is the source of my personal portfolio website, live at **https://nexter2606.github.io/nisarg-parekh.github.io/** (or `https://nexter2606.github.io` if Pages is configured for this repo).

A static, dark-themed, glassmorphic portfolio highlighting my work as a Senior Software Engineer specializing in the Odoo framework (v10 – v19).

## Folder Structure

```
nisarg-parekh.github.io/
├── index.html      # Markup & page structure
├── style.css       # Vanilla CSS — dark glassmorphic layout
├── script.js       # Interactions, reveal animations & active nav tracking
└── README.md       # Project documentation
```

## Features

- Premium dark design with emerald/sky gradient accents
- Glassmorphic sticky navigation with section highlighting on scroll
- Odoo version journey strip (v10 → v19)
- Experience timeline and 14 project showcase cards
- Published Odoo Apps modules section with links
- Fully responsive — mobile, tablet and widescreen
- No build steps — pure semantic HTML5, vanilla CSS and native JavaScript

## Run Locally

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy to GitHub Pages

1. Commit and push to the `main` branch.
2. In the repository settings, enable GitHub Pages from the `main` branch root.
3. The site goes live within 1–2 minutes.
